# Python Programming Assignment 1

Beginner-friendly Python programs organized topic-wise.

## Topics

1. Conditional Statements
2. Loops
3. Strings
4. Data Structures
5. Functions and Recursion
6. Exception Handling
7. Modules and Packages
8. Object-Oriented Programming (OOP)

## How to run

1. Install Python 3.
2. Open a terminal in the folder containing the program.
3. Run a file using:

```bash
python filename.py
```

For example:

```bash
python 01_electricity_bill.py
```

For the geometry package exercise, open a terminal in
`07_Modules_Packages/04_geometry_package` and run:

```bash
python main.py
```
